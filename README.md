# TripRoad

국내 패키지 여행 예약 플랫폼

React와 Spring Boot 기반으로 개발한 국내 패키지 여행 예약 서비스입니다.
사용자는 여행 상품 조회부터 예약, 결제, 후기, 문의, 마이페이지 기능까지 하나의 서비스에서 이용할 수 있습니다.

---

## 프로젝트 소개

TripRoad는 여행 상품 탐색부터 예약, 결제, 여행 준비, 여행 종료 후 후기 작성까지 하나의 플랫폼에서 제공하는 통합 여행 서비스를 목표로 개발한 팀 프로젝트입니다.

## 프로젝트를 통해 배운 점

- React와 Spring Boot를 연동하며 REST API 기반 웹 서비스를 구현했습니다.
- GitHub를 활용한 협업과 프로젝트 병합 과정을 경험했습니다.
- Oracle Database와 HttpSession을 활용한 인증 및 데이터 관리 방식을 익혔습니다.
- 기능 구현뿐 아니라 사용자 경험과 유지보수성을 고려한 개발의 중요성을 배웠습니다.
